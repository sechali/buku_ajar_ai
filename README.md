## 📌 Ringkasan Eksekutif (Executive Summary)

Repositori ini memuat kurikulum, diktat teori, berkas praktikum, dan materi presentasi komprehensif mata kuliah **Kecerdasan Buatan dan Sains Data Pertanian Presisi**. 

Dirancang secara khusus untuk menjembatani disiplin **Teknik Informatika, Sains Data, dan Agroteknologi**, kurikulum ini mengintegrasikan fondasi matematika dan rekayasa perangkat lunak standar industri dengan kasus nyata agroindustri perkebunan kelapa sawit dan pertanian presisi tropis di Indonesia.

Kurikulum ini terdiri atas **100 Modul Lengkap** yang terbagi ke dalam **13 Bagian (*Parts*)**, mencakup teori matematika analitis, komparasi algoritma klasik, pemodelan pembelajaran mesin (*machine learning*), jaringan saraf dalam (*deep learning*), visi komputer (*computer vision*), deteksi objek (*YOLO / Faster R-CNN*), serta *deployment* model di lingkungan *edge computing*.

---

## 🌟 Fitur Unggulan Kurikulum (Key Highlights)

1. **Kontekstualisasi Nyata Sektor Kelapa Sawit & Agrokompleks**:
   * Setiap modul menyajikan studi kasus operasional riil: sortasi otomatis Tandan Buah Segar (TBS) di *loading ramp* Pabrik Kelapa Sawit (PKS), deteksi dini penyakit hawar daun (*Curvularia*) dan jamur busuk pangkal batang (*Ganoderma*), pemantauan defisiensi hara NPK kanopi sawit melalui drone multispektral, estimasi kadar Asam Lemak Bebas (ALB/FFA) CPO, serta prediksi neraca air lahan gambut berbasis sensor IoT telemetri.
2. **Paket Modul Lengkap (600+ Berkas Siap Pakai)**:
   * **100 Diktat Teori Markdown (`docs/`)**: Lengkap dengan penurunan matematis formal, alur berpikir algoritma, dan diagram arsitektur.
   * **100 Jupyter Notebooks Mandiri (`notebooks/`)**: Kode Python modular standar industri yang telah teruji 100% lulus eksekusi tanpa kesalahan (*zero error*).
   * **100 Panduan Pengajar (`instructor_resources/`)**: Memuat Rencana Pembelajaran Semester (RPS), alokasi waktu sesi, rubrik penilaian objektif, serta kunci jawaban soal analitis HOTS (Bloom C3–C5).
   * **200 Dokumen Microsoft Word (`docx/`)**: Format `.docx` resmi dengan persamaan matematika native Word (OMML) dan tata letak publikasi buku ajar.
   * **100 Dek Presentasi PowerPoint (`pptx/` & `slides/`)**: Presentasi widescreen 16:9 modern berstandar eksekutif (800 slide total).
3. **Kesiapan Eksekusi Cloud (Google Colab Ready)**:
   * Seluruh notebook praktikum dilengkapi dukungan eksekusi cloud satu-klik sehingga mahasiswa dapat memanfaatkan akselerasi GPU secara gratis tanpa hambatan spesifikasi komputer lokal.
4. **Metodologi Validasi Ketat**:
   * Menerapkan protokol pencegahan kebocoran data (*data leakage isolation*), pembagian data spasial (*spatial block cross-validation*), serta standarisasi tipe data dan penanganan stabilitas numerik.

| **Part 13** | Integrasi Sistem AI, Deployment Edge, & Studi Kasus Terapan | Modul 13.1 – 13.4.2 | Integrasi model dengan kamera industrial, inferensi deteksi berbasis video & tracking (SORT), pengembangan antarmuka visual (GUI/Web), studi kasus deteksi penyakit daun sawit real-time, sistem monitoring CCTV loading ramp PKS. |

## 🚀 Panduan Memulai (Quick Start Guide)

### 1. Menjalankan di Komputer Lokal (Local Machine)

#### Prasyarat:
* Python 3.10 atau versi yang lebih baru.
* Git terpasang di sistem operasi Anda.

#### Langkah Instalasi:
```bash
# 1. Kloning repositori ini
git clone https://github.com/sechali/buku_ajar_ai.git
cd buku_ajar_ai

# 2. Buat lingkungan virtual terisolasi (Virtual Environment)
python -m venv venv

# Aktifkan virtual environment:
# Di Windows (Command Prompt / PowerShell):
venv\Scripts\activate
# Di Linux / macOS:
source venv/bin/activate

# 3. Instal dependensi pustaka sains data & AI
pip install --upgrade pip
pip install numpy pandas matplotlib seaborn scikit-learn opencv-python torch torchvision jupyterlab
```

#### Menjalankan Jupyter Lab:
```bash
jupyter lab
```
Buka folder `notebooks/` dan pilih modul praktikum yang ingin Anda pelajari.

---

### 2. Menjalankan di Cloud via Google Colab

Setiap notebook di folder `notebooks/` dapat langsung dijalankan di Google Colab. Klik tombol **Open In Colab** yang tertera pada bagian atas setiap berkas notebook praktikum.

Jika Anda membuka notebook secara manual di Colab:
1. Kunjungi [Google Colab](https://colab.research.google.com/).
2. Pilih tab **GitHub**, masukkan URL repositori ini, lalu pilih modul praktikum yang ingin dieksekusi.
3. Untuk modul Part 09 s.d. Part 13 (*Deep Learning & Visi Komputer*), aktifkan akselerasi GPU gratis melalui menu:
   `Runtime` $\to$ `Change runtime type` $\to$ Pilih `T4 GPU` $\to$ `Save`.
